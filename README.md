# Kimpul-Map-AI
Analisis kesesuaian lahan untuk budidaya kimpul (Xanthosoma sagittifolium) di Kabupaten Magelang berbasis data spasial. Repository ini berisi source code, dataset, preprocessing data, analisis parameter tanah dan iklim, klasifikasi kesesuaian lahan (S1, S2, S3, N), visualisasi, serta hasil analisis penelitian.
